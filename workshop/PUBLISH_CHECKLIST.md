# RHD - LifeCore | Publish Checklist

1. Run the GitHub Actions `Build RHD Server Package` workflow and wait for a successful run.
2. Download the `RHD-LifeCore-Workshop` artifact.
3. Extract the `@RHD-LifeCore` folder.
4. Import that folder into the Arma 3 Launcher or use it as the Steam Workshop publisher payload.
5. Enable CBA_A3, cTab+, Antistasi Ultimate and RHD - LifeCore.
6. Confirm `Missions/RHD_LifeCore.Altis.pbo` is present.
7. Test the bundled Altis mission on a dedicated server before public release.
