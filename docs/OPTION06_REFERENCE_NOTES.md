# Option 06 — Six Reference Concepts

The user selected **06 — Modular Duty System** as the master RHD police carrier direction.

The six visual concepts presented before the 3D lock were:

1. Patrol Modular
2. Tactical MOLLE
3. Covert / Low Profile
4. SWAT / Response
5. Supervisor
6. Modular Duty System — **SELECTED**

The six concept images are retained outside the source tree as design references. The production model must remain an original RHD implementation; the supplied/reference images are not treated as source geometry or texture material.

## Visual characteristics carried forward from the selection

- compact modern carrier silhouette
- modular chest placard
- dense but organized MOLLE layout
- detachable radio/admin/medical pouches
- RHD identifier panel
- compatible with woodland, arid, urban and low-visibility presets
- designed to support a larger LifeCore equipment ecosystem
