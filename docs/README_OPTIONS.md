# RHD Police Equipment v1 — Design Gate

## Approved

**Master carrier:** Option 06 — Modular Duty System.

This is the user-approved visual direction for the first RHD Police carrier. The concept remains a rough art-direction reference until the production P3D is modeled and tested in Arma 3.

## Production silhouette

- Compact plate/armor carrier silhouette.
- Broad MOLLE field across front and cummerbund.
- Interchangeable front placard.
- Side-mounted utility/radio zones.
- Rear identifier panel.
- Separate webbing, hardware and plate-cover material zones.
- RHD insignia designed as a replaceable texture/selection rather than permanently baked into geometry.

## Reference gate rule

For every new equipment item, RHD will show six rough visual references before the production 3D model is finalized. A choice is then recorded in this document set so the modeler has an unambiguous target.

## Non-final modeling note

The repository's current config intentionally uses temporary base-game geometry for the scaffold. This allows config/Arsenal integration to be developed first; it is not the final RHD model.
