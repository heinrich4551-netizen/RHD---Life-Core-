# RHD Police Modular Carrier — Reference Selection

**Decision gate:** choose one option before the master vest/carrier P3D is finalized.

The six visual boards were created from the tactical design references supplied in the conversation and are concept references only. They are not third-party Arma assets and are not final models.

## Options

### 01 — Patrol Modular
- Low-profile patrol silhouette
- 3x3 front magazine-cell concept
- RHD POLICE identifier panel
- Radio and utility wings
- Best baseline for general patrol

### 02 — Tactical MOLLE
- Full MOLLE front
- Placard-ready chest
- Side/cummerbund coverage
- Heavy-duty patrol configuration
- Best for tactical officers

### 03 — Covert / Low Profile
- Minimal bulk
- Concealed/low-visibility identifier
- Compact admin pouch
- Civilian-compatible silhouette
- Best for plain-clothes / covert roles

### 04 — SWAT / Response
- Expanded plate coverage
- Medical and rifle cells
- Shoulder/side attachment zones
- Strong RHD identifiers
- Best for response/SWAT

### 05 — Supervisor
- Cleaner front profile
- Large removable ID panel
- Radio/evidence pouch
- Reduced magazine footprint
- Best for command/supervisor variants

### 06 — Modular Duty System
- Interchangeable placards
- MOLLE side panels
- Accessory rails
- Designed around the full 35-slot customization target
- Best long-term master design

## Recommended choice

**06 — Modular Duty System** is the recommended master because it leaves the most room for the requested customization system. Option 01 is the recommended fallback if a lighter patrol-first silhouette is preferred.

## Selection format

Reply with the option number, e.g. `06`.

Do not finalize the P3D, UVs, or texture bake until the option is selected.
