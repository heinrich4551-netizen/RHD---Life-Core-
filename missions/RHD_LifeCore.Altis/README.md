# RHD - LifeCore | Bundled Altis Scenario

Default bundled scenario for the RHD - LifeCore Workshop package.

## Required mods

```text
CBA_A3              450814997
cTab+               2262006564
Antistasi Ultimate  3020755032
RHD - LifeCore
```

ACE3 is optional.

## Included Altis content

- Antistasi Ultimate bridge/campaign start at Kavala.
- RHD Life RP Systems module with all major features enabled.
- Shops, banks and fuel/service points in major towns.
- Apple, cannabis, coca, corn, grapes and peach gathering areas.
- Iron, copper, gold, diamond and oil-sand mining areas.
- Iron, copper, gold and oil refineries.
- Six RHD civilian-pressure districts.
- Kavala jail.
- RHD-branded billboards.

The layout is intentionally stored in the scenario's `mission.sqm` so it can be opened and adjusted in Eden.
