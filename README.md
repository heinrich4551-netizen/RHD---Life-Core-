# RHD - LifeCore

**Arma 3 Life RP + Antistasi Ultimate | Author: LT. Toad | Version 2.2.0**

RHD - LifeCore is packaged for Steam Workshop and the Arma 3 Launcher. The published profile requires CBA_A3, cTab+, and Antistasi Ultimate.

## Required Workshop dependencies

| Addon | Workshop ID | Required |
|---|---:|---|
| CBA_A3 | `450814997` | **Yes** |
| cTab+ | `2262006564` | **Yes** |
| Antistasi Ultimate | `3020755032` | **Yes** |
| ACE3 | — | No; optional |

The RHD addon declares:

```cpp
requiredAddons[] = {"cba_main", "ctab_core", "A3A_core"};
```

Steam Workshop must also have the three IDs above configured as required dependencies. Steam maintains that dependency relationship as publisher metadata; it cannot be generated by `mod.cpp` alone.

## Launcher-ready package

The GitHub Actions artifact `RHD-LifeCore-Workshop` assembles:

```text
@RHD-LifeCore/
├─ addons/
│  ├─ rhd_rhd_lifecore.pbo
│  └─ rhd_rhd_clothing.pbo
├─ assets/branding/RHDLifeCore.jpg
├─ docs/
├─ mod.cpp
└─ meta.cpp
```

For a local install, copy `@RHD-LifeCore` beside the Arma 3 executable and add it to the Launcher. Enable CBA_A3, cTab+, Antistasi Ultimate, and RHD - LifeCore.

## Altis scenario

The repository contains the copy-ready mission source `RHD-LifeCore-MissionSource.Altis` and the mission template under `mission-template/`.

Copy the Altis source into the Arma 3 user missions directory as:

```text
RHD_LifeCore.Altis
```

Open in 3DEN and save to generate `mission.sqm`. The published profile uses the RHD Antistasi Ultimate Bridge plus the RHD Life RP Systems module and is configured for the complete RHD feature stack.

Default location families are:

```text
rhd_shop_<name>
rhd_bank_<name>
rhd_fuel_<name>
rhd_farm_<resource>_<name>
rhd_mine_<resource>_<name>
rhd_refine_<resource>_<name>
rhd_zone_<name>
rhd_jail_<name>
```

Configured resources include apples, cannabis, coca, corn, grapes, peaches, iron ore, copper ore, gold ore, diamonds and oil sand, with iron, copper, gold and oil refining outputs.

## Antistasi Ultimate

The published scenario requires Antistasi Ultimate. A3A remains authoritative for campaign lifecycle, strategic zones, faction control, garrisons, patrols, QRFs, aggression, campaign resources, HQ/Petros, and campaign persistence. RHD supplies the Life RP layer around that strategic simulation.

## ACE3

ACE3 remains optional. When present, RHD adds ACE contextual interaction surfaces for the tablet, EMS, and administration. RHD does not declare `ace_main` as a hard dependency.

## Configuration

Mission gameplay configuration is centralized in:

```text
core/fn_init.sqf
```

This controls admins, jobs/pay, virtual item definitions, refining recipes, gather quantities, dynamic shop pricing/limits/overrides, A3A integration tuning, district pressure, persistence, and startup timing.

## Build / validation

GitHub Actions uses HEMTT and validates repository layout, hard dependencies, addon compilation, PBO presence, source leakage, clothing classes, and Workshop package assembly.

A successful CI build verifies compilation and package assembly. It does not replace an in-game dedicated-server test of the final Workshop item.
