# RHD Life Core

A terrain-agnostic Arma 3 Life RP mission framework designed for **3DEN-first setup**. No external gameplay framework is required for the base mission. Place your locations, NPCs, vehicles, and markers in Eden; the mission scripts discover them by marker prefix at runtime.

## Included

- Persistent player identity, cash/bank, inventory, licenses, job and jail state.
- cTab-backed RHD player tablet for status, jobs, shop, banking and services.
- F6/F7/F8 shortcuts route to cTab pages instead of opening separate RHD dialogs.
- Player tablet can also be opened from ACE Self Actions without an RHD inventory item.
- Lightweight always-visible RHD HUD.
- Farming: Apples, Cannabis Plant, Coca Leaf, Corn Cob, Grapes, Peaches.
- Mining: Iron Ore, Copper Ore, Gold Ore, Diamond, Oil Sand.
- Refining: Iron Ore -> Iron, Copper Ore -> Copper, Gold Ore -> Gold, Oil Sand -> Oil.
- Generic buy/sell shop system using the RHD economy namespace.
- Police, EMS and civilian job templates with basic ticketing and treatment.
- Terrain-independent bank, shop, fuel, farm, mine and refinery locations.
- Performance-conscious ambient civilians and traffic with hard caps and automatic cleanup.
- Rare roadside incidents that can dispatch temporary Police/EMS calls.
- Server-authoritative transactions with caller validation and anti-negative-money/inventory checks.
- Unified UID-gated RHD administrator panel adapted from the XEAT_AdminTool layout.
- Admin panel is separate from the player tablet and is exposed through ACE Self Actions; no admin item or dedicated admin hotkey is required.
- Optional ACE3 integration for interactions and ACE-aware EMS treatment.
- No hard-coded terrain coordinates.

## cTab+

RHD uses [cTab+](https://github.com/jetelain/cTab) as the player-facing tablet surface. The mission opens cTab's `cTab_Tablet_dlg` and creates RHD-owned controls on that display rather than copying cTab addon source.

cTab+ requires CBA_A3. Keep cTab as an external mod; do not copy its PBOs into the mission folder.

See `CTAB_INTEGRATION.md` for the integration details and testing notes.

## ACE3

RHD detects ACE3 at runtime. The base mission remains usable without ACE3, while ACE users gain the RHD Life Tablet, RHD Administration and ACE-aware EMS interactions through ACE interaction menus.

See `ADMIN_AND_ACE_SETUP.md` for ACE installation, admin UID authorization and third-party licensing notes.

## Admin control

All RHD administrator controls are intentionally consolidated into one `RHD_ADMIN` screen. Administrators are identified by Steam64 UID, not player name. Set the allowlist in `core/fn_init.sqf` before hosting:

```sqf
missionNamespace setVariable ["RHD_ADMIN_UIDS", ["7656119XXXXXXXXXX"], true];
```

The unified panel includes player inspection, restore/kill/freeze, teleport, spectate, economy edits, item/job assignment, vehicle repair/refuel/spawn/delete, world time/weather and server announcements.

## 3DEN setup

Create a mission in Eden on any terrain and copy this repository's mission files into the mission folder. The scripts expect these marker prefixes:

- `rhd_farm_*` - farming areas
- `rhd_mine_*` - mining areas
- `rhd_refine_*` - refining areas
- `rhd_shop_*` - shops
- `rhd_bank_*` - banks/ATMs
- `rhd_fuel_*` - fuel stations
- `rhd_garage_*` - reserved for the vehicle ownership/garage expansion
- `rhd_spawn_*` - reserved job/vehicle spawn locations
- `rhd_jail_*` - jail area

Markers are optional. If a feature has no matching marker, players are told that the corresponding location is unavailable rather than being able to use the service anywhere on the map.

## Ambient life

RHD does not attempt to simulate the whole island with permanent AI. A small server-side population is created around active players and removed when it becomes too distant or too old.

Daytime limits are 10 civilians and 4 traffic vehicles globally. Nighttime limits are 5 civilians and 2 traffic vehicles. Roadside incidents are capped at 2. See `PERFORMANCE.md` before raising any limits.

## Installation

1. Make a mission in Eden on the desired terrain.
2. Install CBA_A3 and cTab+ when using the tablet interface.
3. Install ACE3 when using ACE integrations and admin access.
4. Copy the files in this repository into the mission directory.
5. Add your admin Steam64 UID(s) to `RHD_ADMIN_UIDS` in `core/fn_init.sqf`.
6. Save the Eden mission once so Arma generates/updates `mission.sqm`.
7. Place the optional marker prefixes and named objects described above.
8. Preview or host the mission. A dedicated server should use `-filePatching` only for development; the released mission should not depend on it.

This project intentionally avoids terrain-specific coordinates. `mission.sqm` is intentionally generated by Eden rather than fabricated by the framework.
