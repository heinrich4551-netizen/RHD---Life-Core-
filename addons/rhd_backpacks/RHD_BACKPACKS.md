# RHD - LifeCore 16 Backpack Line

The RHD clothing system includes 16 modular tactical/support backpack classes inspired by the supplied plate-carrier and tactical-gear reference style.

| Class | Role | Cargo load |
|---|---|---:|
| `RHD_Bag_Ranger` | Ranger / general tactical | 150 |
| `RHD_Bag_Multicam` | Multi-terrain / field | 150 |
| `RHD_Bag_Black` | Urban tactical / security | 150 |
| `RHD_Bag_Tan` | Contractor / arid | 150 |
| `RHD_Bag_Grey` | Urban utility | 150 |
| `RHD_Bag_Woodland` | Woodland field | 150 |
| `RHD_Bag_Medic` | Medical response | 150 |
| `RHD_Bag_Police` | Police patrol | 150 |
| `RHD_Bag_Security` | Private security | 150 |
| `RHD_Bag_SOF` | Special operations | 150 |
| `RHD_Bag_Utility` | Industrial / civilian utility | 150 |
| `RHD_Bag_Comms` | Radio / communications | 150 |
| `RHD_Bag_LMG` | Support gunner | 150 |
| `RHD_Bag_Marksman` | Recon / marksman | 150 |
| `RHD_Bag_Contractor` | Private contractor | 150 |
| `RHD_Bag_Executive` | Executive protection / VIP | 150 |

All 16 are defined in `CfgVehicles`, inherit from Arma 3 backpack classes, use `scope = 2` and `scopeArsenal = 2`, and set `maximumLoad = 150`. This makes them normal equipable backpacks available to inventory and Arsenal systems.

The production addon uses existing Arma 3 backpack geometries as the base models. The supplied visual concept sheet is a design reference for the intended RHD texture/style families; it is not a redistributed third-party mesh or texture pack.
